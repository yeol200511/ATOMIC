# ATOMIC

118개 원소를 게임처럼 익히는 주기율표 학습 게임. React + TypeScript + Vite 로 만든 브라우저 앱이며, 로그인 없이 LocalStorage 에 진행도를 저장하고 PWA 로 설치해 오프라인에서도 플레이할 수 있습니다.

## 시작하기

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173/ATOMIC/)
npm run build      # 타입 검사 + 프로덕션 빌드
npm run preview    # 빌드 결과 미리보기 (http://localhost:4173/ATOMIC/)
```

주소 끝의 `/ATOMIC/` 은 오타가 아닙니다. GitHub Pages 프로젝트 페이지에 올리느라 서브경로를 기준으로 잡았고, 개발 서버도 배포와 같은 조건에서 확인하도록 같은 경로를 씁니다.

| 스크립트 | 하는 일 |
| --- | --- |
| `npm run dev` | 개발 서버 |
| `npm run build` | `tsc --noEmit` 후 Vite 빌드 (PWA 서비스워커 포함) |
| `npm run preview` | 빌드 결과 확인 |
| `npm run typecheck` | 타입 검사만 |
| `npm run gen:elements` | `src/data/elements.json` 재생성 |
| `npm run gen:icons` | PWA 아이콘·파비콘 재생성 |

## 배포

**https://yeol200511.github.io/ATOMIC/**

`main` 에 push 하면 `.github/workflows/deploy.yml` 이 타입 검사·빌드를 거쳐 GitHub Pages 에 올립니다. 저장소 설정의 **Settings → Pages → Source** 를 `GitHub Actions` 로 한 번 바꿔 두어야 동작합니다.

서브경로 설정은 `vite.config.ts` 위쪽 `BASE` 한 곳에서 관리합니다. `base`·매니페스트 `start_url`·`scope`·`id`·`navigateFallback` 이 모두 이 값을 따라갑니다. 저장소 이름을 바꾸면 `BASE` 만 고치면 됩니다.

## 게임 모드

| 모드 | 문제 | 답하는 방법 |
| --- | --- | --- |
| 위치 맞추기 | 원소 이름 또는 기호 | 빈 주기율표에서 해당 칸 클릭 |
| 원자번호 맞추기 | 원소 이름 또는 기호 | 원자번호 입력 |
| 원소 이름 맞추기 | 원자번호 | 이름 또는 기호 입력 |
| 원자모형 맞추기 | 보어 모형 (전자껍질 애니메이션) | 보기 4개 중 선택 |
| 기호 맞추기 | 원소 이름 | 기호 입력 |
| 랜덤 종합 퀴즈 | 위 다섯 가지 무작위 | — |

- 난이도: Easy(1~20번) · Normal(1~56번) · Hard(1~118번)
- 분량: 10문제 · 20문제 · 무한모드
- 시간 제한 ON/OFF (문제 유형·난이도에 따라 13~25초)

## 점수 규칙

```
정답        기본 100점 × 난이도 배수 (Easy 1.0 / Normal 1.15 / Hard 1.3)
연속 정답   콤보 1당 +20점 (15콤보에서 상한)
빠른 정답   시간 제한 ON 일 때 남은 시간에 비례해 최대 +50점
오답        콤보 초기화
```

한 판이 끝나면 `점수/20 + 정답 수×3 + 최고 콤보×2` 만큼 경험치를 받고, 일일 도전과제를 달성하면 추가 경험치가 붙습니다.

## 학습 기능

- **오답노트** — 틀린 원소가 자동으로 쌓이고, 두 번 맞히면 사라집니다. 노트에 모인 원소만 골라 다시 풀 수 있습니다.
- **원소 도감** — 118개 전체 검색(이름·영문명·기호·번호·별칭)과 분류 필터. 원소를 누르면 원자량·전자배치·보어 모형·설명을 볼 수 있습니다.
- **업적 20종 · 레벨 · 일일 도전과제 3종** — 매일 0시에 날짜 시드로 새 과제가 배정됩니다.

## 원소 데이터

`src/data/elements.json` 은 **생성물입니다.** 원소를 고치려면 `scripts/generate-elements.mjs` 의 기본 표를 고치고 `npm run gen:elements` 를 실행하세요.

- 전자배치는 아우프바우 순서로 채운 뒤, 바닥상태가 다른 21개 원소(Cr·Cu·Nb·Mo·Ru·Rh·Pd·Ag·La·Ce·Gd·Pt·Au·Ac·Th·Pa·U·Np·Cm·Lr)만 예외표로 덮어씁니다.
- 보어 모형 껍질은 전자배치를 주양자수별로 합쳐서 유도합니다. 예: `Na → 1s² 2s² 2p⁶ 3s¹ → K 2 · L 8 · M 1`
- 생성기는 원소 118개, 껍질 전자 합 = 원자번호, 기호·이름 중복 없음을 검증하고 실패하면 멈춥니다.

## 저장 방식

로그인 없이 브라우저 LocalStorage 두 곳에만 저장합니다.

- `atomic.settings.v1` — BGM·효과음·애니메이션·테마·마지막 게임 설정
- `atomic.progress.v1` — 경험치·레벨·최고 점수·최고 콤보·플레이 횟수·정답률·최근 20판 기록·오답노트·업적·일일 도전과제

시크릿 모드처럼 저장소를 쓸 수 없는 환경에서는 메모리에 담아 두고 게임은 그대로 진행됩니다(브라우저를 닫으면 사라집니다). 설정 화면에서 전체 초기화할 수 있습니다.

## 소리

효과음과 배경음악은 오디오 파일 없이 WebAudio 로 직접 합성합니다. 받을 파일이 없으니 오프라인에서도 그대로 소리가 납니다. 브라우저 자동재생 정책 때문에 첫 클릭이나 키 입력이 있어야 오디오가 깨어납니다.

## 접근성·반응형

- 다크 모드가 기본이며 설정에서 라이트 모드로 바꿀 수 있습니다.
- 애니메이션 OFF 설정은 전자 궤도 회전과 폭죽 효과까지 함께 멈춥니다.
- 모바일에서는 문제 패널이 위, 주기율표가 아래로 쌓이고 주기율표는 가로 스크롤됩니다.

## 알아두면 좋은 점

- 시각적 진입 애니메이션은 브라우저의 `requestAnimationFrame` 으로 돌아갑니다. 화면이 없는 헤드리스 환경에서는 rAF 가 스스로 돌지 않아 페이드가 끝나지 않을 수 있습니다(실제 브라우저에서는 정상). 자동화 테스트를 붙인다면 설정에서 애니메이션을 끄거나 가상시간을 진행시키세요.
- 원소 이름은 대한화학회 명칭을 기본으로 쓰되, 채점할 때는 익숙한 옛 이름도 함께 정답으로 받습니다(나트륨/소듐, 칼륨/포타슘, 요오드/아이오딘 등).
