# 게임 본체 스펙

118개 원소를 게임처럼 익히는 브라우저 학습 게임. 로그인 없이 LocalStorage 에 진행도를 담고, PWA 로 설치해 오프라인에서도 돌아간다.

**상태: 구현 완료** (2026-07-31 기준, `tsc --noEmit` 0건 · `npm run build` 성공)

## 게임 모드

여섯 가지 모드를 제공한다.

| 모드 | 문제로 주는 것 | 답하는 방법 |
| --- | --- | --- |
| 위치 맞추기 | 원소 이름 또는 기호 | 빈 주기율표에서 해당 칸 클릭 |
| 원자번호 맞추기 | 원소 이름 또는 기호 | 원자번호 입력 |
| 원소 이름 맞추기 | 원자번호 | 이름 또는 기호 입력 |
| 원자모형 맞추기 | 보어 모형 전자껍질 애니메이션 | 보기 4개 중 선택 |
| 기호 맞추기 | 원소 이름 | 기호 입력 |
| 랜덤 종합 퀴즈 | 위 다섯 가지를 무작위로 | 각 유형을 따름 |

- 난이도 세 단계: Easy(1~20번) · Normal(1~56번) · Hard(1~118번)
- 분량 세 가지: 10문제 · 20문제 · 무한모드
- 시간 제한을 켜고 끌 수 있고, 제한 시간은 문제 유형과 난이도에 따라 13~25초

## 점수 규칙

```
정답        기본 100점 × 난이도 배수 (Easy 1.0 / Normal 1.15 / Hard 1.3)
연속 정답   콤보 1당 +20점, 15콤보에서 상한
빠른 정답   시간 제한을 켠 경우 남은 시간에 비례해 최대 +50점
오답        콤보 초기화
```

한 판이 끝나면 `점수/20 + 정답 수×3 + 최고 콤보×2` 만큼 경험치를 받는다. 일일 도전과제를 달성하면 경험치가 더 붙는다.

## 학습 기능

- **오답노트** — 틀린 원소가 자동으로 쌓이고 두 번 맞히면 사라진다. 노트에 모인 원소만 골라 다시 풀 수 있다.
- **원소 도감** — 118개 전체를 이름·영문명·기호·번호·별칭으로 검색하고 분류로 거를 수 있다. 원소를 누르면 원자량·전자배치·보어 모형·설명이 나온다.
- **업적 20종 · 레벨 · 일일 도전과제 3종** — 도전과제는 매일 0시에 날짜 시드로 새로 배정된다.

## 채점 규칙

원소 이름은 대한화학회 명칭을 기본으로 쓰되, 채점할 때는 익숙한 옛 이름도 정답으로 받는다(나트륨/소듐, 칼륨/포타슘, 요오드/아이오딘 등). 입력은 공백·대소문자를 지우고 비교한다.

## 원소 데이터

`src/data/elements.json` 은 생성물이라 직접 고치지 않는다. 원소를 고치려면 `scripts/generate-elements.mjs` 의 기본 표를 고치고 `npm run gen:elements` 를 실행한다.

- 전자배치는 아우프바우 순서로 채운 뒤, 바닥상태가 다른 21개 원소(Cr·Cu·Nb·Mo·Ru·Rh·Pd·Ag·La·Ce·Gd·Pt·Au·Ac·Th·Pa·U·Np·Cm·Lr)만 예외표로 덮어쓴다.
- 보어 모형 껍질은 전자배치를 주양자수별로 합쳐 유도한다. 예: `Na → 1s² 2s² 2p⁶ 3s¹ → K 2 · L 8 · M 1`
- 생성기는 원소가 118개인지, 껍질 전자 합이 원자번호와 같은지, 기호·이름이 겹치지 않는지 검증하고 어긋나면 멈춘다.

## 저장 방식

로그인 없이 LocalStorage 두 곳에만 담는다.

- `atomic.settings.v1` — BGM·효과음·애니메이션·테마·마지막 게임 설정
- `atomic.progress.v1` — 경험치·레벨·최고 점수·최고 콤보·플레이 횟수·정답률·최근 20판 기록·오답노트·업적·일일 도전과제

시크릿 모드처럼 저장소를 쓸 수 없는 환경에서는 메모리에 담고 게임은 그대로 진행한다(브라우저를 닫으면 사라진다). 설정 화면에서 전체 초기화할 수 있다.

## 소리·접근성

- 효과음과 배경음악은 오디오 파일 없이 WebAudio 로 합성한다. 받을 파일이 없어 오프라인에서도 소리가 난다. 브라우저 자동재생 정책 때문에 첫 클릭이나 키 입력이 있어야 오디오가 깨어난다.
- 다크 모드가 기본이고 설정에서 라이트 모드로 바꾼다.
- 애니메이션 OFF 설정은 전자 궤도 회전과 폭죽 효과까지 함께 멈춘다.
- 모바일에서는 문제 패널이 위, 주기율표가 아래로 쌓이고 주기율표는 가로로 스크롤된다.

## 키보드 단축키

| 키 | 동작 |
| --- | --- |
| `Enter` | 답 제출 |
| `1` ~ `4` | 원자모형 문제 보기 선택 |
| `Space` | 피드백에서 다음 문제로 |
| `Esc` | 일시정지 / 이어서 하기 · 창 닫기 |
| `/` | 도감 검색창 포커스 |
| `?` | 단축키 목록 |
